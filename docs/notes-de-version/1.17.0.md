## Nouveautés

- Outils HTML : bouton « Réinitialiser » pour effacer les données de l'outil (retour au premier lancement)
- Git : dépôt GitHub partagé (plusieurs petits projets dans un seul dépôt, un dossier chacun)
- Actions de projet : ouvrir un fichier du projet (page HTML, texte, PDF…) en plus de lancer une commande
- Renommer le dossier d'un projet : liens, groupes, épingles, récents et conversations de Claude suivent
- Groupes : un groupe qui a des sous-groupes affiche ses projets rangés par sous-groupe
- Catégories : choisir ou changer la couleur (clic sur la pastille ou clic droit)
- Renommer un projet depuis Toolkit (nom affiché ; le dossier ne change pas)
- Raccourcis : ignorer le faux « keydown » sans touche envoyé par la saisie automatique (erreur pendant l'import)
- Simulation du tactile limitée à la page HTML : l'interface de Toolkit garde la souris
- Simulation du tactile (la souris agit comme un doigt) pour les outils HTML et l'aperçu HTML de l'onglet Code
- Import : un fichier seul (page HTML, script…) peut être importé, rangé dans son propre dossier de projet

## Corrections

- Projets : « Repartir de zéro » (fichiers hors Git à la Corbeille, données des pages HTML effacées) pour voir le projet comme un nouvel utilisateur
- Détails : expression du nom du dépôt partagé corrigée
- Projets : choisir l'action par défaut et ajouter / modifier / supprimer des actions depuis Toolkit
